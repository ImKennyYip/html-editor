HTML Editor Editor Project. In this tutorial, you will learn how to code an html code editor online using the iframe.

Throughout the tutorial, you will learn how to embed an open source code editor, render the result with an iframe, and automatically refresh the changes whenever the changes are made in the html code editor. For this tutorial, we will use the open source ace code editor, which includes dark theme, syntax highlighting, automatic tag closing, and line numbers.

Ace Code Editor: https://ace.c9.io/
Cdn: https://cdnjs.com/libraries/ace/
